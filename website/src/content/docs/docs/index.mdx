cetra is an open-source platform for observing and evaluating LLM applications. It records traces, measures cost and latency, scores output and raises alerts. It ingests OpenTelemetry, and runs as one binary with its own storage engine, a web UI, and Python and TypeScript SDKs.

## How it fits together

cetra works as a loop: instrument, inspect, evaluate, alert.

**Instrument.** Your application sends spans to cetra over OTLP, either through the cetra SDKs or through any OpenTelemetry instrumentation. cetra reads the common LLM conventions and records inputs, outputs, token usage and cost.

**Inspect.** The UI shows each trace as a tree and a timeline, groups traces into sessions and users, and filters them by any field. You can also query the data with SQL.

**Evaluate.** Scores attach a value to a trace or span. You write them by hand, from code, or with evaluators and LLM judges that run on live traces. Datasets and experiments let you compare versions of your application.

**Alert.** Alert rules watch metrics such as error rate, cost and latency, and notify you through Slack, a webhook or email.
