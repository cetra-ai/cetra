This page tells you where to go for help and how to report a security problem.

## Bugs and questions

- **A bug or a missing feature:** open an issue at [github.com/cetra-ai/cetra/issues](https://github.com/cetra-ai/cetra/issues). For a bug, attach a debug bundle: [Reporting a bug](/docs/help/reporting-a-bug/) shows how to write one with `cetra debug-bundle` and what to check before you share it. Do not paste prompts, completions or keys.
- **A question:** read the [FAQ](/docs/help/faq/) and [Troubleshooting](/docs/help/troubleshooting/) first, then ask by email.
- **Anything else:** write to `hello@cetra.sh`.

## Report a vulnerability

Do not open a public issue for a security problem. Use GitHub's private vulnerability reporting on [cetra-ai/cetra](https://github.com/cetra-ai/cetra/security/advisories/new), or email `hello@cetra.sh` with SECURITY in the subject. Say which version is affected and how to reproduce the problem. Keep the details private until a fix is released.

To harden your own installation, see [Security](/docs/self-hosting/security/).
