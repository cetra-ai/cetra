### `ApiError`

{/* untested: signature */}
```python
class ApiError(Exception):
    status: int
    code: str | None
    detail: str | None
    errors: Sequence[Mapping[str, object]]
```

Raised by `Client`, `evaluate` and `aevaluate` when the API answers with an error. `status`, `code` and `detail` come from the server's problem document, and `errors` holds the field errors of a refused dataset item. See [Errors](/docs/reference/python/scores-datasets-experiments/#errors).

### `Client`

{/* untested: signature */}
```python
class Client:
    def __init__(self, *, api_key: str | None = None, base_url: str | None = None) -> None: ...
```

The REST client for datasets, experiments and annotation queues. It reads the key and the base URL the way `init()` does and raises `ConfigError` without a key. ### `ExperimentResult`

{/* untested: signature */}
```python
class ExperimentResult:
    experiment_id: str
    experiment_name: str
    dataset_id: str
    dataset_version: int
    runs: tuple[Run, ...]
    scorer_errors: Mapping[str, int]
    error_count: int  # property

    def summary(self) -> str: ...
    def assert_min(self, name: str, threshold: float) -> None: ...
```

What `evaluate` returns: one `Run` per item and repetition, in item order. `summary()` prints the means and counts; `assert_min` raises `AssertionError` when a scorer's mean is below the threshold, which gates CI. See [Experiments](/docs/reference/python/scores-datasets-experiments/#experiments).

### `evaluate`

{/* untested: signature */}
```python
def evaluate(*, dataset: str | Dataset, task: Callable[..., Any], scorers: Sequence[Callable[..., Any]] = (), experiment_name: str | None = None, description: str | None = None, metadata: Mapping[str, object] | None = None, dataset_version: int | None = None, concurrency: int = 8, repetitions: int = 1, client: Client | None = None) -> ExperimentResult: ...
```

Blocks until the pending spans and scores are exported. Call it at the end of every serverless invocation. See [Serverless](/docs/reference/python/opentelemetry/#serverless).

### `shutdown`

{/* untested: signature */}
```python
def shutdown() -> None: ...
```

Flushes, then stops the SDK and uninstruments what it enabled. `init()` registers it with `atexit`. See [Initialize](/docs/reference/python/#initialize).

A sync and async context manager that runs its body inside one span. The handle's setters record the input, the output and the metadata. See [Manual spans and llm_span](/docs/reference/python/tracing/#manual-spans-and-llm_span).
