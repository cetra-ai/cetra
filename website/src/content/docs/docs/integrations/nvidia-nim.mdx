## Set up

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: calls NVIDIA NIM and needs NVIDIA_API_KEY */}
```python
import os

import cetra
from openai import OpenAI

cetra.init(instrument=["openai"])

client = OpenAI(base_url="https://integrate.api.nvidia.com/v1", api_key=os.environ["NVIDIA_API_KEY"])
response = client.chat.completions.create(
    model="meta/llama-3.3-70b-instruct",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)
print(response.choices[0].message.content)

cetra.flush()
```

## What you get

- Each chat completion is an `llm` span with the provider `nvidia_nim`.
- Input and output token counts come from the response.
- No built-in price: add a custom model price in Settings → Model prices to get a cost.
- With `cetra.init(instrument=["openai"])`, the endpoint host is in `server.address`, and cetra names the provider from it.

## Limits

- A self-hosted NIM container on your own host shows the provider `openai`, as any local server does.
- No spans of NVIDIA NIM are captured in the repository. cetra maps the host `integrate.api.nvidia.com` to the provider `nvidia_nim`.
- The built-in prices have no NVIDIA NIM rows, so cost is empty until you add a custom model price in Settings → Model prices.
- With plain OpenInference or the official OpenAI instrumentation in Python, the provider shows as `openai`: they do not record the endpoint. Use `cetra.init(instrument=["openai"])` or OpenLLMetry.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
