## Set up

Write the agent as a Strands agent, as on the [Strands Agents](/docs/integrations/strands/) page. Start cetra and point Strands at cetra's tracer provider before you create the agent. Set `CETRA_API_KEY` to your `sk-cetra-…` key.

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: needs CETRA_API_KEY and an AWS account for the AgentCore runtime */}
```python
import cetra
from strands.telemetry import StrandsTelemetry

cetra.init()
StrandsTelemetry(tracer_provider=cetra.tracer_provider())

# Create the Strands agent and run it as on the Strands Agents page.

cetra.flush()
```

  </TabItem>
</Tabs>

## What you get

An AgentCore agent that runs Strands code produces the spans listed on the [Strands Agents](/docs/integrations/strands/) page: the agent span, the event loop cycles, a `chat` `llm` span for each model call, and a `tool` span for each tool call.

## Limits

- cetra was tested with the Strands cases, not on AgentCore. The spans above come from Strands running locally.
- The export from the AgentCore runtime to cetra is not tested, because the test needs an AWS account.
- The fixtures were captured with `strands-agents` 1.65.0.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
