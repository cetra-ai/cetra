## Set up

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: calls Groq and needs GROQ_API_KEY */}
```python
import os

import cetra
from groq import Groq

cetra.init(instrument=["groq"])

client = Groq(api_key=os.environ["GROQ_API_KEY"])
response = client.chat.completions.create(
    model="openai/gpt-oss-20b",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)
print(response.choices[0].message.content)

cetra.flush()
```

## Through the OpenAI client

Groq also serves an OpenAI-compatible endpoint. The provider comes from the endpoint host.

{/* untested: calls Groq through the OpenAI client and needs GROQ_API_KEY */}
```python
import os

import cetra
from openai import OpenAI

cetra.init(instrument=["openai"])

client = OpenAI(base_url="https://api.groq.com/openai/v1", api_key=os.environ["GROQ_API_KEY"])
response = client.chat.completions.create(
    model="openai/gpt-oss-20b",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)
print(response.choices[0].message.content)

cetra.flush()
```

## What you get

- Each chat completion is an `llm` span with the provider `groq`.
- Input and output token counts come from the response.
- Cost comes from the built-in prices.
- Through the OpenAI client, the endpoint host is in `server.address`, and cetra names the provider from it.

## Limits

- The fixtures were captured with groq 1.7.0 and openinference-instrumentation-groq 0.1.40.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
