## Set up

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: calls Hugging Face Inference Providers and needs HF_TOKEN */}
```python
import os

import cetra
from openai import OpenAI

cetra.init(instrument=["openai"])

client = OpenAI(base_url="https://router.huggingface.co/v1", api_key=os.environ["HF_TOKEN"])
response = client.chat.completions.create(
    model="deepseek-ai/DeepSeek-R1:fastest",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)
print(response.choices[0].message.content)

cetra.flush()
```

## What you get

- Each chat completion is an `llm` span with the provider `huggingface`.
- Input and output token counts come from the response.
- No built-in price: add a custom model price in Settings → Model prices to get a cost.
- With `cetra.init(instrument=["openai"])`, the endpoint host is in `server.address`, and cetra names the provider from it.

## Limits

- The router picks a provider for each call; the span names Hugging Face, not the provider that served it.
- No spans of Hugging Face Inference Providers are captured in the repository. cetra maps the host `router.huggingface.co` to the provider `huggingface`.
- The built-in prices have no Hugging Face Inference Providers rows, so cost is empty until you add a custom model price in Settings → Model prices.
- With plain OpenInference or the official OpenAI instrumentation in Python, the provider shows as `openai`: they do not record the endpoint. Use `cetra.init(instrument=["openai"])` or OpenLLMetry.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
