cetra can trace LiteLLM calls from Python through the OpenInference LiteLLM instrumentation.

<Backing tests={["sdks/python/tests/test_instrument.py::test_other_registry_entries_import[litellm]"]} />

## Install

```bash
pip install "cetra-sdk[litellm]" litellm
```

## Set up

{/* untested: needs cetra-sdk[litellm] and a provider key */}
```python
import litellm

import cetra

cetra.init(instrument=["litellm"])

litellm.completion(
    model="gpt-4o-mini",
    messages=[{"role": "user", "content": "What is the weather in Paris?"}],
)

cetra.flush()
```

## What you get

cetra reads the spans of the OpenInference LiteLLM instrumentation with the OpenInference convention. See [Semantic conventions](/docs/concepts/conventions/).

## Limits

- No captured spans of this instrumentation are in the repository. The only check is an SDK test that imports the instrumentor when the extra is installed. This page does not say which fields a LiteLLM call fills.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
