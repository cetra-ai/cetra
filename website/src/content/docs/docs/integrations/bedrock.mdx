cetra can trace Amazon Bedrock calls from Python through the OpenInference Bedrock instrumentation.

<Backing tests={["sdks/python/tests/test_instrument.py::test_other_registry_entries_import[bedrock]"]} />

## Install

```bash
pip install "cetra-sdk[bedrock]" boto3
```

## Set up

{/* untested: needs cetra-sdk[bedrock], boto3 and AWS credentials */}
```python
import boto3

import cetra

cetra.init(instrument=["bedrock"])

client = boto3.client("bedrock-runtime")
client.converse(
    modelId="anthropic.claude-3-5-sonnet-20240620-v1:0",
    messages=[{"role": "user", "content": [{"text": "What is the weather in Paris?"}]}],
)

cetra.flush()
```

## What you get

cetra reads the spans of the OpenInference Bedrock instrumentation with the OpenInference convention. See [Semantic conventions](/docs/concepts/conventions/).

## Limits

- No captured spans of this instrumentation are in the repository. The only check is an SDK test that imports the instrumentor when the extra is installed. This page does not say which Bedrock operations are traced or which fields they fill.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
