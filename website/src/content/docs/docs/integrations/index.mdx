Use this page to find how to connect your framework, provider or instrumentation library to cetra.

| Integration | Python | TypeScript | How | Tested against |
|---|---|---|---|---|
| [OpenAI](/docs/integrations/openai/) | ✓ | ✓ | `instrument=["openai"]` or `openai(OpenAI)` | captured |
| [Anthropic](/docs/integrations/anthropic/) | ✓ | ✓ | `instrument=["anthropic"]` or `anthropic(Anthropic)` | captured |
| [Google Gen AI](/docs/integrations/google-genai/) | ✓ | — | `instrument=["google-genai"]` | captured |
| [Amazon Bedrock](/docs/integrations/bedrock/) | ✓ | — | `instrument=["bedrock"]` | SDK test |
| [LiteLLM](/docs/integrations/litellm/) | ✓ | — | `instrument=["litellm"]` | SDK test |
| [LangChain and LangGraph](/docs/integrations/langchain/) | ✓ | ✓ | `instrument=["langchain"]` or `langchain(…)` | captured (Python), SDK test (TypeScript) |
| [LlamaIndex](/docs/integrations/llama-index/) | ✓ | — | `instrument=["llama-index"]` | SDK test |
| [Vercel AI SDK](/docs/integrations/vercel-ai-sdk/) | — | ✓ | `aiTelemetry()` | captured |
| [OpenAI Agents SDK](/docs/integrations/openai-agents/) | ✓ | — | `instrument=["openai-agents"]` | captured |
| [CrewAI](/docs/integrations/crewai/) | ✓ | — | `instrument=["crewai"]` | SDK test |
| [DSPy](/docs/integrations/dspy/) | ✓ | — | `instrument=["dspy"]` | SDK test |
| [Google ADK](/docs/integrations/google-adk/) | ✓ | — | ADK's own OpenTelemetry spans | captured |
| [OpenInference](/docs/integrations/openinference/) | ✓ | ✓ | point its exporter at cetra | captured |
| [OpenLLMetry (Traceloop)](/docs/integrations/openllmetry/) | ✓ | ✓ | point its exporter at cetra | captured |
| [OpenTelemetry GenAI](/docs/integrations/opentelemetry-genai/) | ✓ | ✓ | the official `opentelemetry-instrumentation-*` packages | captured |
| [From Langfuse](/docs/integrations/from-langfuse/) | ✓ | — | keep the Langfuse SDK, export its spans to cetra | captured |
| [From Laminar](/docs/integrations/from-laminar/) | ✓ | — | keep the Laminar SDK, export its spans to cetra | captured |

"Captured" means the repository holds spans recorded from the real library, and a test checks how cetra reads them. "SDK test" means an SDK test checks the helper, and the repository holds no recorded spans for it. A ✓ for TypeScript means a helper in `@cetra-ai/sdk`, or a TypeScript library whose spans are captured. A — means no helper or captured run exists for that language: you can still use the library's own OpenTelemetry instrumentation with [Send OpenTelemetry](/docs/get-started/opentelemetry/).
