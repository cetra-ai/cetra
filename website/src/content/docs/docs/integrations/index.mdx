## Migrating

| Integration | Python | TypeScript | How | Tested against |
|---|---|---|---|---|
| [From Laminar](/docs/integrations/from-laminar/) | ✓ | — | keep the Laminar SDK, export its spans to cetra | captured |
| [From Langfuse](/docs/integrations/from-langfuse/) | ✓ | — | keep the Langfuse SDK, export its spans to cetra | captured |

<CardGrid>
  <LinkCard title="From Laminar" description="Keep the Laminar SDK and send its spans to cetra." href="/docs/integrations/from-laminar/" />
  <LinkCard title="From Langfuse" description="Keep the Langfuse SDK and send its spans to cetra." href="/docs/integrations/from-langfuse/" />
</CardGrid>

"Captured" means the repository holds spans recorded from the real library, and a test checks how cetra reads them. "Hand-written" means the spans in the repository were written from the vendor's attribute reference. "SDK test" means an SDK test checks the helper, and the repository holds no recorded spans. "Setup only" means the page shows the setup; nothing in the repository records this integration's spans. A ✓ for TypeScript means a helper in `@cetra-ai/sdk`, or a TypeScript library whose spans are captured. A — means no helper or captured run exists for that language: you can still use the library's own OpenTelemetry instrumentation with [Send OpenTelemetry](/docs/get-started/opentelemetry/).

Anything else that speaks OpenTelemetry works through [Send OpenTelemetry](/docs/get-started/opentelemetry/).
