## Set up

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: calls OpenAI through BeeAI and needs OPENAI_API_KEY */}
```python
import asyncio
import os

import cetra
from beeai_framework.adapters.openai import OpenAIChatModel
from beeai_framework.agents.requirement import RequirementAgent
from beeai_framework.tools import tool

cetra.init(instrument=["beeai"])


@tool
def get_weather(city: str) -> str:
    """Look up the weather for a city."""
    return f"sunny in {city}"


async def main() -> None:
    llm = OpenAIChatModel("gpt-4o-mini", api_key=os.environ["OPENAI_API_KEY"])
    agent = RequirementAgent(
        llm=llm,
        tools=[get_weather],
        instructions="You are a weather assistant.",
        name="weather-agent",
    )
    await agent.run("What is the weather in Paris?")


asyncio.run(main())

cetra.flush()
```

## What you get

- The run is an `agent` span named after the agent, with the final answer as a second `agent` span and a `tool` span.
- Each model call is an `llm` span with the messages, the tool definitions and the token counts.
- Each tool call is a `tool` span with the tool's input and output.

## Limits

- Do not also enable `openai`: each model call would be recorded twice and counted twice.
- Cost is the one BeeAI reports (through LiteLLM), not cetra's price table. A model LiteLLM cannot price reports a cost of 0.
- TypeScript is not supported: OpenInference's BeeAI instrumentation only covers 2025 versions of the TypeScript framework.
- The `beeai` extra needs Python 3.14 or earlier: the OpenInference BeeAI instrumentation does not support Python 3.15 yet.
- The fixture was captured with beeai-framework 0.1.85 and openinference-instrumentation-beeai 0.1.36.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
