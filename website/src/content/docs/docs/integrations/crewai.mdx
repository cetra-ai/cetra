## Install

```bash
pip install "cetra-sdk[crewai]" crewai
```

## Set up

{/* untested: needs cetra-sdk[crewai] and a model key */}
```python
import cetra

cetra.init(instrument=["crewai"])

# Build and run your crew as usual. CrewAI runs are traced from here on.
```

## What you get

cetra reads the spans of the OpenInference CrewAI instrumentation with the OpenInference convention. See [Semantic conventions](/docs/concepts/conventions/).

## Limits

- No captured spans of this instrumentation are in the repository. The only check is an SDK test that imports the instrumentor when the extra is installed. This page does not say which CrewAI operations are traced.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
