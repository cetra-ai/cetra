## Install

```bash
pip install "cetra-sdk[llama-index]" llama-index
```

## Set up

{/* untested: needs cetra-sdk[llama-index] and a model key */}
```python
import cetra

cetra.init(instrument=["llama-index"])

# Build and query your index as usual. LlamaIndex calls are traced from here on.
```

## What you get

cetra reads the spans of the OpenInference LlamaIndex instrumentation with the OpenInference convention. cetra supports the OpenInference `retriever`, `reranker` and `embedding` span kinds. See [Semantic conventions](/docs/concepts/conventions/).

## Limits

- No captured spans of this instrumentation are in the repository. The only check is an SDK test that imports the instrumentor when the extra is installed. This page does not say which LlamaIndex operations are traced.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
