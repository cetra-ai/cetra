## Set up

<Tabs syncKey="lang">
  <TabItem label="Python">

{/* untested: calls Qwen (Alibaba Cloud Model Studio) and needs DASHSCOPE_API_KEY */}
```python
import os

import cetra
from openai import OpenAI

cetra.init(instrument=["openai"])

client = OpenAI(base_url="https://dashscope-intl.aliyuncs.com/compatible-mode/v1", api_key=os.environ["DASHSCOPE_API_KEY"])
response = client.chat.completions.create(
    model="qwen-plus",
    messages=[{"role": "user", "content": "What is the capital of France?"}],
)
print(response.choices[0].message.content)

cetra.flush()
```

## What you get

- Each chat completion is an `llm` span with the provider `dashscope`.
- Input and output token counts come from the response.
- Cost comes from the built-in prices.
- With `cetra.init(instrument=["openai"])`, the endpoint host is in `server.address`, and cetra names the provider from it.

## Limits

- Model Studio keys are bound to a region; use that region's base URL.
- No spans of Qwen (Alibaba Cloud Model Studio) are captured in the repository. cetra maps the hosts `dashscope-intl.aliyuncs.com`, `*.maas.aliyuncs.com` to the provider `dashscope`.
- With plain OpenInference or the official OpenAI instrumentation in Python, the provider shows as `openai`: they do not record the endpoint. Use `cetra.init(instrument=["openai"])` or OpenLLMetry.
- If a field is missing, look at the span's **Attributes** tab and compare it with [Span attributes](/docs/reference/attributes/).
