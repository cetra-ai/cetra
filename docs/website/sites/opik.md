# Opik by Comet (https://www.comet.com/site/products/opik/)

## Hero
- **Headline (verbatim):** "AI Observability & Evals For the Agentic Era". "Agentic Era" is in a periwinkle gradient.
- **Subhead (verbatim, short):** "Opik logs every step your agent takes, from user interactions to context retrieval and tool calls…"
- **Primary CTA:** "Try Opik Free" (periwinkle rgb(96,100,255) / #6064FF) → `comet.com/signup?from=llm`.
- **Secondary CTA:** "Get Demo →" (text link); the nav also has Get Demo and Try Opik Free.
- **Hero visual:** a large, real light-theme product screenshot entering the first viewport (CRM Agent logs list, span tree, agent graph, token-usage YAML). The page sits under Comet's corporate nav with breadcrumbs (Home > Products > Opik), so Opik reads as one product page of a larger ML company.

## Structure
1. Comet nav and breadcrumb.
2. Hero and screenshot.
3. "Compare Opik vs. Alternative…" callout box → "Compare Platforms" (it names LangSmith, Langfuse, Arize, Braintrust, Galileo).
4. Problem statement, then four alternating screenshot rows: Trace & Debug, Evaluate (30+ metrics), Monitor, Coding Agent Spend (Sankey of Claude Code/Codex cost).

7. "Open Source & Ready to Run" box with a GitHub button "comet-ml: 23k ★".
8. Dev → Unit Testing → Production lifecycle diagram.
9. Periwinkle "Try Opik Free" band, newsletter form, footer with Capterra 4.4, G2, HIPAA, SOC, ISO badges.

## Proof
Big-brand logo marquee mid-page (Uber, Netflix, NatWest, Stellantis). GitHub 23k stars, but the button says "comet-ml", so it may be the org rather than the repo. Review-site and compliance badges are in the footer only. No testimonials, no numbers, no benchmarks.

## Product shown how
A real screenshot in the first viewport, then real screenshots in every row (traces, experiments, monitors, cost Sankey, playground, optimizer). Static images, small inside dark frames; no video, no code, no demo.

## Visual style
Roboto throughout (h1 50px, weight 600): a generic corporate feel. Deep navy-black background (≈ #0A0B1E) with a blue-violet glow, periwinkle #6064FF accent, white text, light-theme screenshots for contrast. Medium density, template-like alternating rows. Comet's orange-red logo is the only warm colour.

## Pricing / self-host / comparison pages
Pricing was not captured (it lives on Comet's pricing). Self-host is reduced to one paragraph: "download the code from GitHub and run it locally", with "a highly scalable and industry-compliant version ready for enterprise teams". No command, no footprint shown; competitors.md lists MySQL + ClickHouse + Redis + S3 + Zookeeper and Java + Python services. A dedicated "Compare Platforms" page sits high on the homepage (second block).

## What makes it sell
- A real product screenshot above the fold and on every feature row.
- Fortune-500 logos and the backing of an established ML company (Comet).
- A comparison CTA placed right after the hero, for buyers in evaluation mode.
- Distinctive agentic features (Ollie writes fixes, prompt optimizer, coding-agent spend).

## Weaknesses we can exploit
- **The self-host story is one vague sentence;** the heaviest stack in the category (MySQL, ClickHouse, Redis, Zookeeper, Java and Python) is hidden.
- **Opik lives inside Comet's corporate site:** breadcrumbs, ML-experiment nav, a "Subscribe to Comet" form. It doesn't feel like a developer product.
- **Generic visuals** (Roboto, template rows) and no quantified proof.

## Steal for cetra
- A "Compare vs alternatives" callout box directly after the hero, linking to honest comparison pages.

## Scores
- Beauty 2/5: generic Roboto corporate template on navy.
- Selling 3/5: clear CTAs and big logos, but no numbers.
- Clarity (5-second test) 4/5: headline and screenshot make it obvious.
- Proof 3/5: strong logos, stars; no quotes or metrics.
- Product-showing 4/5: real screenshots above the fold and throughout.
