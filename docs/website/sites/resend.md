# Resend (https://resend.com)

## Hero
- Headline: "Email for developers"
- Subhead: "The best way to reach humans instead of spam folders. Deliver transactional and marketing emails at scale."
- Primary CTA: "Get started" (dark pill with a subtle border, links to /signup). Secondary: "Documentation" (text link to resend.com/docs). Above the headline sits a gradient-bordered announcement pill: "What you missed at Resend Forward →" (links to /forward).
- Visual: a photoreal, slowly rotating black 3D Rubik's-style cube on the right, with a diagonal light streak across the black background (5 videos and 1 canvas on the page).

## Structure
1. Hero as above.
2. Logo wall, 2×6 (Warner Bros, Max, Raycast, Mistral AI, Replit, Gumroad, Decathlon, Supabase…), with "Explore Enterprise".
3. "Integrate *tonight*": 3D mail icon, a row of 13 language/runtime icons (Node, Python, Rust, Go, CLI, SMTP…), framework sub-tabs, and an 18-line send-email snippet with "View on GitHub / Download ZIP".
4. "First-class developer experience": two cards, Test mode (a stream of HTTP 200 JSON responses) and Modular webhooks (an event timeline: Bounced / Complained / Opened).
5. "Write using a delightful editor": a broadcast editor UI.
6. "Go beyond editing": Contact management and Broadcast analytics cards (98% deliverability).
7. "Develop emails using React": a split view with a TSX file tree and code on the left and the rendered email on the right, linked to their open-source react-email library.
8. "Reach humans, not spam folders": a 3×3 grid of deliverability features (DMARC, BIMI, dedicated IPs…).
9. Single big quote from Guillermo Rauch (CEO of Vercel), centred.
10. "Everything in your control": three tabs (analytics / visibility / domain auth) over a real Metrics dashboard.
11. "Beyond expectations": a horizontally scrolling testimonial row (MrBeast VP Eng, Gumroad CEO, Mintlify co-founder…).
12. Closing CTA "Email reimagined. Available today." and footer.

## Proof
- Logo wall immediately after the hero.
- One famous-founder quote mid-page.
- A carousel of named testimonials near the end.
- Open source shown as a credential (react-email, "View on GitHub").
- No numbers (volume, users) and no benchmarks on the homepage.

## Product shown how
- Code appears in the second section, about one viewport down, with real copy-pasteable code in 13 languages.
- Then real dashboard and editor UI, a JSON response stream, an event timeline and a live React-to-email preview.
- 16 code blocks. Abstract 3D art is used only for the hero and the section icons.

## Visual style
- Type: "domaine" serif at 96px, weight 400, letter-spacing −0.96px for display (an elegant editorial serif, unusual for dev tools). "Inter Website" for body text and UI headings, mono for code.
- Colour: pure black #000000 background, white and grey text, glassy dark cards with 1px borders and soft top highlights. Accents are tiny: a violet gradient on "tonight", green for success states, red and orange status pills.
- Dark, cinematic, generous spacing (about 12,400px page).
- Signature devices: a glossy 3D app-icon above each section title, the serif headlines, light streaks, and the gradient announcement pill.

## Pricing / comparison pages
- Pricing (pages/resend-pricing): a serif "Pricing" title and a Transactional / Marketing toggle. A volume slider (3,000 → 3M+ emails) reprices four cards (Free $0 / Pro $20 / Scale $90 / Custom). Each card states its overage rate ("Extra emails: $0.90 / 1,000"). There's a link "Are you an AI agent? See pricing", then pay-as-you-go and add-on cards with prices in the headings, a long comparison table, a 15-question FAQ and "Start sending tonight".
- No vs page captured.
- Docs: top-nav "Docs" dropdown, plus "Documentation" as the hero's secondary CTA.

## What makes it sell
- Promise of speed: "Integrate tonight" is followed by a working snippet in the user's language, so the cost of trying is a 5-minute evening.
- A famous-name quote from a peer founder carries a lot of weight with developers.
- Developer-native proof: showing HTTP 200 responses, webhook events and a test mode tells developers it's built by engineers.
- The serif and 3D treatment make a commodity (email API) feel premium and desirable.
- The pricing slider with explicit overage removes billing anxiety, and the AI-agent pricing link is a smart touch.

## Weaknesses
- No hard numbers (emails/day, customers, latency) anywhere on the homepage.
- The hero visual (an abstract cube) says nothing about the product; the product only appears below the fold.

## Steal for cetra
- After the hero, add an "Integrate tonight"-style block with language tabs (Python / TS / OTLP / curl) and a minimal instrumentation snippet.
- Show developer-native feedback loops: e.g. a streaming feed of incoming spans/traces with IDs and status, like their HTTP 200 stream.
- Use a split code-and-result panel (code on the left, rendered trace or eval result on the right).
- Add a usage slider on pricing (spans/month) with an explicit overage rate, plus a machine-readable "for AI agents" pricing link.

## Scores
- Beauty 5/5: cinematic black, serif display, glossy icons, superb polish.
- Selling 4/5: "Integrate tonight" plus quotes sell, but numbers are missing.
- Clarity 5/5: "Email for developers" is instantly clear.
- Proof 4/5: strong logos and famous quotes, no metrics.
- Product-showing 4/5: code and dashboards early, but the hero is abstract.
