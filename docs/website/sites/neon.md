## Hero

- **Subhead:** none. A mono eyebrow above the headline reads "NEON IS PART OF THE DATABRICKS PLATFORM".
- **Primary CTA:** "Get started" (white pill on black; href not captured, the nav pair is Log in / Sign up).
- **Secondary CTA:** "Read the docs" (outlined pill).
- **Nav:** Discord and GitHub "23.3k" stars. A slim top banner announces new features (Object Storage, Functions, AI Gateway) with dithered gradient corners.
- **Hero visual:** a full-bleed, black, slow-moving abstract of green/teal vertical bars, like a spectrogram or glitch texture (canvas/video; the page has 5 canvases and 7 videos). The headline sits low on the left. A customer logo strip (BCG, Pepsi, Retool, Meta, Bitso, Framer…) closes the first viewport.

## Structure
1. Feature banner, nav (Discord, stars), dark hero with the abstract animation and logo strip.
2. "01 BUILD YOUR BACKEND": a large two-tone statement ("Not just a Database." in white, rest in grey), then five staggered mini-UI cards (Postgres autoscaling bars, Better Auth sign-up, Functions "Starting…", branching storage tree, AI Gateway POST).
3. "02 OPERATE IT WITH AGENTS": three points (Instant operations, Branch everything, Safe automation) beside an animated agent chat ("Test two login flows… Create a branch for each.") and a branch graph.
4. "03 SCALE YOUR APP AND AGENT": three stages in mono highlighted headings:
   - "WHERE STARTUPS START": 100K+ projects, startup logos and a retro dialog window.
   - "WHERE AGENT PLATFORMS DEPLOY": stacked windows, and a quote from the founder of Encore.
   - "WHERE THE FORTUNE 500 SCALES": a giant wireframe globe with enterprise logos (easyJet, Ubisoft…) and "70% Fortune 500 … build on the Databricks Platform".
5. Mint-green section: a statement with highlighter-marked phrases, then tabs (Lakebase Architecture / Advanced Autoscaling / Built by Databricks) and a clean architecture diagram (Compute → Pageserver/Safekeepers → Lake object storage).
6. Dark: an autoscaling chart toggle ("Avoid outages / Save costs") comparing fixed provisioning (red outage spike) with Neon autoscaling (green), plus an "outages prevented this year" counter.
7. "Backed by giants": Databricks logo, 20M+ databases started daily, 3M+ developers.
8. Mint: "Pay for what you use…", "View Pricing", and four cards (Powerful Free Tier, Starts at $0, Efficient dev/test, No-Fee AI Gateway).
9. Closing: a terrain/cube render, "The world's most advanced backend platform.", Get started / Read the docs / a green `$ npx neon init` copy button. Footer with compliance badges (SOC 2, ISO 27001, HIPAA…) and "All systems operational".

## Proof
- Logo strip in the first viewport; startup and enterprise logos in section 4.
- Numbers: 100K+ projects, 20M+ databases started daily, 3M+ developers, 70% of the Fortune 500 (a Databricks stat), 23.3k GitHub stars.
- One founder quote (Encore).
- Databricks ownership is used as a trust anchor.
- Compliance badges in the footer.

## Product shown how
- Stylised mini-UIs and animated diagrams rather than screenshots: the agent chat, branch trees, the autoscaling chart and the architecture diagram. They are polished and on-brand but are not the real console.
- No code blocks on the page except the `npx neon init` button at the end.

## Visual style
- **Type:** Inter at weight 400 for the 56px h1 (light and elegant, -2.24px tracking), with a monospace for eyebrows, the big outlined section numerals (01/02/03) and retro window chrome.
- **Colours:** pure black #000 dominates. The brand green is around #2ED19A (sampled; the npx button), with teal/green on dark, and pale mint sections (#E4F1EA) with highlighter marks. White pill buttons.
- **Mode and density:** mostly dark with mint light interludes. Sparse, cinematic, very generous spacing.
- **Signature devices:** two-tone headline sentences (white lead, grey continuation), giant numbered chapters, dithered/halftone textures, the wireframe globe and terrain render, mono highlighted labels.

## Pricing / comparison pages
- Not captured. The homepage pricing teaser frames value as usage-based: "Pay for what you use, not for the infrastructure you might need". Four cards: 100 free projects, $0 start, scale-to-zero dev/test, at-cost AI gateway.
- No vs pages seen.
- Docs: "Docs" is a top-level nav item and the secondary CTA, both in the hero and at the end.

## What makes it sell
- A three-chapter narrative (Build → Operate with agents → Scale) gives a long page a clear arc.
- The scale ladder (startups → agent platforms → Fortune 500) lets every buyer find themselves and see they won't outgrow it.
- The architecture diagram is shown openly, which reassures technical buyers about how it works.
- A before/after chart (fixed provisioning outage vs autoscaling) dramatises the key benefit.
- Premium cinematic art direction signals a serious, well-funded platform.

## Weaknesses
- The hero headline is jargon-heavy ("Lakebase Postgres") and the art is abstract. It doesn't say why Neon is better in 5 seconds.
- No real product UI and no code early. Developers must trust illustrations.
- Databricks branding competes with Neon's own identity.

## Steal for cetra
- A chaptered homepage (01 Ingest / 02 Evaluate / 03 Scale on one box) with big mono numerals and two-tone statement headlines.
- A clean architecture diagram section (OTLP → WAL → memtable → Parquet + DataFusion; SQLite; embedded UI) to earn trust with engineers.
- A before/after chart toggle (e.g. "5-service stack" vs "one binary": RAM, containers, ops pages).
- A closing CTA trio: Get started / Read the docs / a copyable install command button.

## Scores
- Beauty 5/5 — cinematic dark art direction, refined type, rich motion.
- Selling 4/5 — strong narrative and scale proof; vague hero.
- Clarity 3/5 — "Lakebase Postgres" jargon; benefit not instantly clear.
- Proof 4/5 — logos, big numbers, Databricks, compliance; one quote.
- Product-showing 3/5 — illustrative mini-UIs, no real console or code.
