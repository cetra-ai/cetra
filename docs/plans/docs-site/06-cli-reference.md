**Commit subject:** `Generate the CLI reference from the clap definitions`

## Steps

### 1. The renderer

In `mod tests` of `crates/cli/src/main.rs` (it is test-only code, so no `unwrap` rule applies):

```rust
/// The CLI reference page (D-W-7): every visible command's long help, in command order.
fn cli_reference() -> String {
    use clap::CommandFactory;
    let mut root = Cli::command();
    root.build();
    let mut page = String::from(
        "---\n\
         title: CLI\n\
         description: Every cetra command and option, generated from the binary's own help.\n\
         ---\n\n\
         <!-- Generated by `just docs-gen` from crates/cli/src/main.rs. Do not edit. -->\n\n\
         The `cetra` binary runs the server (`cetra serve`), administers a data directory \
         (`cetra admin`) and talks to a running server (`cetra login`, `cetra query`, `cetra traces`, \
         `cetra projects`). This page is generated from the binary's `--help`.\n",
    );
    fn walk(command: &clap::Command, path: &str, page: &mut String) {
        let level = path.split(' ').count().min(4) + 1; // `cetra` is ##
        page.push_str(&format!("\n{} `{path}`\n\n", "#".repeat(level)));
        page.push_str("```text\n");
        page.push_str(command.clone().render_long_help().to_string().trim_end());
        page.push_str("\n```\n");
        for sub in command.get_subcommands() {
            if sub.is_hide_set() || sub.get_name() == "help" {
                continue;
            }
            walk(sub, &format!("{path} {}", sub.get_name()), page);
        }
    }
    walk(&root, "cetra", &mut page);
    page
}

#[test]
fn cli_reference_is_up_to_date() {
    let path = std::path::Path::new(env!("CARGO_MANIFEST_DIR"))
        .join("../../website/src/content/docs/docs/reference/cli.md");
    let expected = cli_reference();
    if std::env::var_os("CETRA_DOCS_WRITE").is_some() {
        std::fs::write(&path, &expected).expect("write the CLI reference");
        return;
    }
    let actual = std::fs::read_to_string(&path).unwrap_or_default();
    assert!(
        actual == expected,
        "website/src/content/docs/docs/reference/cli.md is stale: run `just docs-gen`"
    );
}
```

Notes:
- The page is `.md` (plain Markdown), so its generated-file note is an HTML comment.
- The page must pass `check-terms.mjs` (description under 160 characters) and `check-samples.mjs` (only `text` fences).
- If `render_long_help` output contains the version string, the page would change at every release. Check: `cetra --help` must not print the version. If it does, call `root = root.version(None)` … only if clap allows; otherwise report it.
- If `about = "LLM observability server"` reads badly as the page's first help block, leave it: changing the binary's help text is outside this phase. Mention it in the report.

### 2. The recipe

After `openapi` in the `justfile`:

```make
# Regenerate the generated docs pages (D-W-7): the CLI reference
docs-gen:
    CETRA_DOCS_WRITE=1 cargo test -p cetra-cli cli_reference_is_up_to_date
```

Run `just docs-gen` to write the page, then `cargo test -p cetra-cli cli_reference_is_up_to_date` without the variable to see it pass.
