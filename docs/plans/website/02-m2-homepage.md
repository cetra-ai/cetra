### Deviation from the design (fixed in the design doc in H3)

Design §3 planned coded HTML scenes of the UI for the hero and the chapters. This plan uses **real screenshots of the UI in its dark theme** instead, made by the docs' screenshot tool from the UI on its mocks:
- they are the actual product, so they stay true;
- they are regenerated by one command when the UI changes (`just docs-screenshots`);
- they cost no hand-built UI.

The terminal transcript of the agents section is the one coded scene. The design doc was updated with this plan.

1. `screenshots.mjs`:
   - In the main block, **delete** the context-level `await context.addInitScript(() => { … localStorage.setItem("cetra.theme", "light") … })` and its comment. Playwright does not define the order of context and page init scripts, so the theme is set per page instead.
   - In `shoot(context, shot)`, as the first statements inside the `try` block (before `page.clock.setFixedTime`), add:

```js
    // Each shot starts from empty storage. The docs show the light theme; a marketing shot sets
    // `"theme": "dark"`, the UI's default.
    const theme = shot.theme ?? "light";
    await page.emulateMedia({ colorScheme: theme });
    await page.addInitScript((value) => {
      try {
        localStorage.clear();
        localStorage.setItem("cetra.theme", value);
      } catch {
        // storage unavailable: the UI's default theme stays
      }
    }, theme);
```
