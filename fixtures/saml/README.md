# SAML test keys

These are test keys for `cetra-saml`'s test IdP (track SA). The key and certificate pairs are generated by the `openssl req -x509` commands in `docs/plans/sa-saml/01-m1-crate.md` (SA1.1, step 5); those commands regenerate them. `weak-rsa-1024` exists to be refused: the crate must reject its 1024-bit key. `attacker-rsa` is a second, valid key that is never in a trusted set, so a Response it signs must fail. None of these keys protects anything: they are public test material, and nothing outside the tests trusts them.
