# cetra brand

The cetra logo is the **Caetra c** (D189): the rim of a *caetra*, the small round shield the name
comes from, opened into a lowercase c, with the shield's boss at its centre.

## Files

| File | Use |
|---|---|
| `cetra-logo.svg` | the mark and the name, on light backgrounds (README, site header) |
| `cetra-logo-on-dark.svg` | the same, on dark backgrounds |
| `cetra-mark.svg` | the mark alone, teal, on light backgrounds |
| `cetra-mark-on-dark.svg` | the mark alone, light teal, on dark backgrounds |
| `cetra-mark-black.svg`, `cetra-mark-white.svg` | one-colour uses: print, stamps, photos |
| `cetra-icon.svg` | the app icon: the white mark on a teal tile with rounded corners |
| `cetra-avatar-512.png` | the square tile for avatars (GitHub organization, social profiles) |

The web UI's favicons (`web/public/favicon.svg`, `favicon.ico`, `apple-touch-icon.png`) are made
from `cetra-icon.svg`.

The name in the logo is set in [Space Grotesk](https://github.com/floriankarsten/space-grotesk)
(SIL Open Font License 1.1), weight 600, tracking −1.4 at 46 px, and converted to outlines, so the
files need no font.

## Colours

| Name | Hex | Use |
|---|---|---|
| Teal | `#0f766e` | the mark on light backgrounds, the icon tile |
| Light teal | `#2dd4bf` | the mark on dark backgrounds |
| Ink | `#141414` | the name on light backgrounds |
| Paper | `#f5f5f4` | the name on dark backgrounds |

## Rules

- Keep clear space around the logo of at least the boss's diameter (a quarter of the mark's height).
- Smallest sizes: the mark at 16 px, the logo with the name at 20 px high.
- Use the files as they are: don't stretch, rotate, recolour outside the table, outline or add
  shadows, and don't set the name in another typeface next to the mark.
- On a photo or a busy background, use the icon tile, or the black or white mark.
